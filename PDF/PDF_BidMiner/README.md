# BidMiner 使用说明

## 日常使用

1. 把要处理的 PDF 放进 `pdfs` 文件夹。
2. 双击 `run.bat`。
3. 等待窗口提示处理完成，到 `output` 文件夹查看 Excel。

每次运行会生成新的 Excel，不会覆盖之前的结果。运行前请关闭正在查看的结果 Excel，以免保存失败。

Excel 的“信息类型”分为“招标信息”和“投标结果公告”两类。金额统一为万元；未提供、不适用或未能识别的字段显示 `/`，具体原因见“提取备注”。

## 第一次使用

- 电脑需要安装 Python，推荐 64 位 Python 3.11 或 3.12。安装时勾选 `Add Python to PATH`。下载地址：https://www.python.org/downloads/
- `api_key.json` 需要填写有效的阿里百炼 Key；已经配置好就不必重复填写。
- 双击 `run.bat` 后，程序会自动准备运行环境和安装依赖。首次启动需要联网，请耐心等待，不要关闭窗口。

## 遇到问题

- 没有 PDF：把 PDF 放进 `pdfs` 后重新运行。
- 网络或 Key 报错：检查网络连接和 Key 是否有效。
- 提取失败：查看 Excel 的“提取备注”，保留错误提示或窗口截图，联系提供软件的人。
- 字段显示 `/`：可能是原文未提供信息；提取结果仍需对照原文核验。

## 模型自动维护

- 当前文本模型是 `qwen-flash`，视觉模型是 `qwen3-vl-plus`，型号保存在 `model_config.json`。
- 首次运行会读取阿里云官方模型下线公告，之后每隔 **15 天**在启动时联网检查一次。电脑或程序关闭期间不会检查，下次启动时会补查。
- 当前型号列入官方下线名单时，程序会提前从配置允许的候选中自动切换，显示新型号并保存配置。文本模型当前候选是 `qwen-plus`；切换后费用及提取结果可能变化，请核对输出。视觉模型暂未配置候选。
- 如果没有可用候选，窗口会显示官方替代建议、配置文件的完整位置以及需要修改的项目。请按下面“自行更换模型”的步骤操作，保存并重新运行即可。
- 公告读取失败时，会提示检查未完成，并根据本地已确认记录处理；下次启动会再次尝试联网。检查失败不代表模型正常。
- `.model_check.json` 是程序自动生成的检查记录，不需要手动编辑。

下线检查依赖官方网页的文字名单和结构，只检查最近一个已下线批次及未来批次，并保留之前成功识别的记录；不能保证识别所有历史或图片公告。它也不能解决账户欠费、调用限流、模型权限或地域不匹配等问题，发生这些报错时请把窗口截图发给提供软件的人。

## 自行更换模型

当窗口提示“没有可自动替换的候选”时，请按以下步骤自行更换，无需修改 Python 文件。

1. 查看窗口给出的官方公告和“官方替代建议”。打开 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，在模型广场中查找建议型号，确认自己的账号可以调用，并查看价格和调用说明。若公告没有给出型号，就在模型广场选择合适的模型并复制它的 **模型 ID**，不要复制中文展示名称。
2. 确认用途和接口兼容：文字型 PDF 使用支持 DashScope `Generation` 接口、非思考模式的文本模型；图片型 PDF 使用支持图片输入、DashScope `MultiModalConversation` 接口和非思考模式的视觉模型。模型详情或调用示例中可查看这些信息。不要把图片模型配置成只能接收文字的型号；若新型号要求不同的接口或参数，请选择兼容型号，或等待程序适配更新。
3. 关闭正在运行的程序窗口。在 `run.bat` 所在文件夹找到 `model_config.json`，右键 → **打开方式 → 记事本**。如果找不到文件，以窗口提示的完整路径为准；不要新建一个 `.txt` 文件。
4. 根据窗口提示，只改对应那一行右边英文双引号中的型号：`text_model` 是文字模型，`vision_model` 是图片模型。其他行和每行末尾的逗号都保留。例如，若文本模型的官方建议是 `qwen-plus`，把：

   ```json
   "text_model": "qwen-flash",
   ```

   改成：

   ```json
   "text_model": "qwen-plus",
   ```

   如果提示的是图片模型，就修改 `"vision_model": "qwen3-vl-plus",` 这一行，将其中的 `qwen3-vl-plus` 换成确认可用的视觉模型 ID。不要把本例里的 `qwen-plus` 填到图片模型那一行。
5. 按 **Ctrl+S** 保存，关闭记事本，然后重新双击 `run.bat`。启动后会显示实际使用的文本和视觉型号，检查它是否已经改变。不需要等待下一次 15 天公告检查，也不需要修改 `text_fallbacks`、`vision_fallbacks` 或删除检查记录。
6. 先处理一份 PDF，核对 Excel 中的项目名、金额等字段，确认正常后再批量处理。

如果提示“模型配置读取失败”，重新用记事本检查：英文双引号和逗号是否保留、是否误用了中文引号、是否删除了文件开头和结尾的 `{`、`}`。按上述示例修正并保存后重新运行。若仍提示原型号已下线，请确认保存的是窗口给出的配置文件，并重新查看官方公告选择型号。

## 更新已有软件

提供软件的人需要将新版 `main.py`、`launcher.py`、`model_config.py`、`model_config.json` 和本说明一起发给用户。用户关闭程序后，将这些文件覆盖到原来 `run.bat` 所在文件夹，再双击 `run.bat`。请保留原来的 `api_key.json`、`prompt.txt`、`pdfs` 和 `output`。

之后若只是更换模型型号，用户按“自行更换模型”修改配置并重新运行即可；如果需要调整程序以适配新模型，再安装程序更新。

请保留 `main.py`、`launcher.py`、`model_config.py`、`model_config.json` 和 `prompt.txt`，它们是程序运行所需文件。日常更换模型只需要按上述步骤修改 `model_config.json`。

# 修改记录 — BidMiner

## 2026-10-16 — 模型配置与下线公告检查

### 背景与目标

文本模型调整为 qwen-flash，视觉模型继续使用 qwen3-vl-plus。启动时按 15 天周期读取阿里云官方下线公告，提前切换到配置允许的候选，减少模型退市造成的中断。

### 影响与兼容性

- 保留现有“招标信息 / 投标结果公告”两类信息类型及配套提示词，增加 Excel 分类回归测试。
- 型号与检查周期集中在 model_config.json；文本允许候选为 qwen-plus，视觉候选为空。候选必须兼容现有接口，自动切换不代表账号权限、配额或模型识别质量得到保证。
- 首次升级需同时提供 main.py、launcher.py、model_config.py、model_config.json 和 README.md，覆盖到原程序目录。保留用户的密钥、提示词、PDF 与输出结果。
- 程序未运行时不检查；检查到期后在启动时补查。只在成功获取公告时更新时间戳，联网失败时仍按缓存中的已确认记录处理。
- 无候选时保留当前型号，显示官方替代建议、配置完整路径、对应字段和记事本修改步骤；用户自行保存兼容型号并重新运行。配置读取失败时给出格式检查及说明文档位置。

### 文件与实现

| 文件 | 说明 |
|---|---|
| model_config.py | 配置校验、官方公告获取、检查缓存与允许候选切换；原子写入配置与缓存 |
| model_config.json | 默认型号、候选及 15 天检查周期 |
| main.py | 加载模型配置；关闭思考模式；限制接口超时；记录接口错误与不可解析输出 |
| launcher.py | 显式安装并检查 requests 依赖；失败时引导用户优先按上方提示自行处理 |
| README.md | 日常使用、自动维护边界和面向初学者的更新步骤 |
| test_model_config.py | 配置、检查周期、切换、网络失败、缓存、接口错误与 Excel 回归测试 |
| smoke_test_models.py | 生成虚构文字/图片 PDF，调用真实接口并验证 Excel；调用会产生少量费用 |

### 验证

- `PYTHONDONTWRITEBYTECODE=1 PYTHONIOENCODING=utf-8 py -3 -B -m unittest discover -v`：24 项测试通过。覆盖既有两类信息类型的 Excel 输出、启动器失败出口的自行处理指引、15 天到期边界、允许候选、文字及图片模型的自行更换指引、手动保存后下次启动立即生效、配置格式错误的修正提示、历史记录保留、断网、损坏缓存、配置无法保存、模拟启动到 Excel、欠费不重试、限流最多三次、超时恢复、密钥脱敏与截断输出拒绝。
- 使用 Python `compile` 和 `ast.parse(feature_version=(3, 10))` 检查全部 Python 文件：通过，不在目录内生成编译缓存。

以下为同步前的真实接口与启动器验证记录，本次同步未重复调用付费模型接口：

- `PYTHONIOENCODING=utf-8 py -3 smoke_test_models.py`：真实 qwen-plus 候选接口通过；虚构文字和图片 PDF 均成功生成 Excel，项目名称、城市、采购人及 16 万元预算正确。
- 使用空的临时检查目录读取真实官方公告：检查成功，识别 qwen-turbo 对应 https://www.aliyun.com/notice/118177 ，当前默认型号未切换。
- `py -3 launcher.py install`：真实 Windows 独立环境创建和依赖安装成功；检查 BAT 的 ASCII 编码及 CRLF 换行通过；模拟依赖安装失败时给出含 requests 的手动安装命令并向上报告失败。
- 将启动器的业务目录指向临时目录，保留真实环境检查和子进程启动，执行 `launcher.command_run()`：虚构文字 PDF 经真实 qwen-flash 接口生成 Excel，项目名及 16 万元预算正确；临时测试数据自动移除。

### 已知限制与后续

- 下线检查依赖官方网页及公告接口结构，识别最近已下线批次和未来批次的文字名单，并合并历史缓存；不保证识别所有历史公告、图片名单或新增公告格式。结构变化或联网失败时提示检查未完成。
- 下线检查无法解决欠费、限流、地域和权限问题。更换型号前需确认接口兼容性、价格及账号可用性；接口或参数不兼容的新模型仍需程序适配更新。
- 图片识别可能误读金额：先前测试出现过 16 万元识别为 160 万元；正常字体与 300 DPI 测试图本轮验证正确，不构成消除视觉误识别的保证。
- 自动化测试使用隔离临时目录；真实接口验证仅发送虚构数据。
